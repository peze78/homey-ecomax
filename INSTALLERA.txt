Packa upp direkt i projektmappen och ersätt befintliga filer.

Kör:
node --check drivers\ecomax\driver.js
node --check drivers\ecomax\device.js
node --check lib\sensors.js
node --check lib\mappings.js
homey app validate --level publish
homey app run

När allt fungerar:
git add .
git commit -m "Added translations and Burning off mode for v1.1.4"
git push
homey app publish

Välj No på automatisk versionshöjning. Versionen är redan 1.1.4.
