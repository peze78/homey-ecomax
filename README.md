# ecoMAX Controller

Monitor your ecoMAX heating system directly from Homey.

ecoMAX Controller gives you a clear overview of your boiler, temperatures, pumps,
operating mode and other important values from ecoNET24-connected ecoMAX controllers.

## Features
- Boiler temperature
- Flue gas temperature
- Buffer tank temperatures
- Heating circuit temperatures
- Operating mode
- Pump status
- Flue gas fan
